🐧 Entorno de Desarrollo

⚠️ Windows — Problemas
  • Permisos y rutas conflictivas
  • Ollama inestable o lento
  • speech_recognition da guerra
  • pyttsx3 con errores de audio
  • Terminal limitada (CMD / PowerShell)
✅ Linux Mint — Solución
  • Ollama corre estable y rápido
  • Python preinstalado
  • Sin drama de permisos
  • Librerías de voz sin problemas
  • Terminal poderosa (bash)
💡 Setup actual
DUAL BOOT · WINDOWS + LINUX MINT

Mini Jarvis se desarrolla y ejecuta en Linux Mint, aprovechando la estabilidad de un entorno Linux sin perder el acceso a Windows cuando se necesite.

# Instalar Ollama en Linux Mint
curl -fsSL https://ollama.com/install.sh | sh

# Jalar el modelo
ollama pull qwen2.5-coder:3b

# Instalar dependencias
pip install requests

// 09

🛠️ Troubleshooting

PROBLEMA Ollama no responde o es muy lento
SOLUCIÓN Usar Linux Mint vía dual boot. Ollama corre mucho más estable en Linux.
PROBLEMA Errores de permisos en Windows
SOLUCIÓN Desarrollar en Linux Mint donde los permisos de Python y terminal son mucho más simples.
PROBLEMA speech_recognition / pyttsx3 con errores de audio
SOLUCIÓN En Linux Mint instalar portaudio19-dev y python3-pyaudio para evitar conflictos.
PROBLEMA Código solo guardado en Windows
SOLUCIÓN Subir el código a GitHub o copiarlo a una USB antes de trabajar en Mint.
